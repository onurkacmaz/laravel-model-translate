# Security Policy

## Supported Versions

Only the latest released version receives security fixes.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, use [GitHub's private vulnerability reporting](https://github.com/onurkacmaz/laravel-model-translate/security/advisories/new)
or email kacmaz.onur@hotmail.com. Please include a description of the issue, the steps to reproduce it, and the
affected versions. You will receive a response as soon as possible, and a fix will be released after the issue has
been confirmed.
